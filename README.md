# E-commerce

В данном проекте реализован функционал 
по сбору данных о продуктах и категорий этого продукта.

---

## Методы класса Product

### new_product
Метод принимает на вход словарь и соответственно присваивает каждому атрибуту значение

### price
Геттер возвращает цену продукта. Сеттер проверят новую заданную цену, 
и если она меньше или равна 0 - выводит соответствующее сообщение

### __str__
Магический метод для строкового отображения объекта

### __add__
Магический метод для сложения стоимостей товаров

Так же класс Product наследует класс-миксин MixinLog, который позволяет вывести информацию
в виде ```Product('Продукт1', 'Описание продукта', 1200, 10)```

---

## Методы класса Category

### add_product
Метод добавляет продукт в категорию

### products
Геттер возвращает список продуктов

### info_product
Метод возвращает информацию о продукте

### __str__
Магический метод для строкового отображения объекта
